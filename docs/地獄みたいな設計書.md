# 安全なデバイスのサーバー側との接続

* 初期設定時(及びファクトリーリセット時)にデバイス側はUUIDを自分で生成する。

* AppはBLEを利用しデバイスを捜索、接続。

* AppはデバイスにWi-Fiの情報を登録する。

* ログイン済みAppからサーバーにOwnerTokenを署名付きで申請する。

* AppはデバイスにOwnerTokenをそのまま送信する。

* デバイスはサーバーに自身のUUID/ModelをAuthorizationヘッダにOwnerTokenをつけて登録する。

* ※通信は実運用時はTLSを利用

# 安全なデバイスのOwnerTokenの更新

* デバイスからサーバーに更新要求(この際、現状のOwnerTokenを利用する。UUID/Modelもつける)

* サーバー側で既存の情報を照合

* 正しいのならば新しいトークンを返却

* デバイスは返却されたトークンをテスト。

* 正しく動作すればROMを置き換える。

# 着座検知とサーバーへの通知

## 着座/起立の物理的な検知
* 着座の検知は物理的な接点を用いて行う


構造としては一般的なスイッチと同じである。ただ、単純にしてデカくして耐久を上げる。これが目標。

## サーバーへの通知
* 着座の通知はデバイスからサーバーに対して行う。
* 起立に関してもサーバーへ毎度通知を行う。この際、数秒及び数分の起立なら無視する。

# 振動及びその拡張機能の実行
## 実行に至るまでの計算
* デバイス、サーバー側両方で検知を行う。
### デバイス及びサーバー側で基準を超過する着席が確認された場合
1. スケジュールをサーバー側で確認する。
2. 不正がなければユーザーに警告の通知を発報する。
3. それでも着席状態が維持されれば振動及びその拡張機能が実行される。

### デバイスとサーバーとのデータの共有について(仮)
* デバイス→サーバーへのポーリングが主な通信である。(現在の着座データも送信)(10秒間隔)
* サーバーは基本、次回起こる可能性があるかもしれないイベントの時刻を返却する。
* イベント時間に近づいた場合、１秒間隔のポーリングに切り替える。
* もし何かのイベントがサーバー側で起きた場合、デバイスに返却する。
* ポーリング速度の返却はサーバー側からとする。

## クライアント向けAPI

### アカウント登録
メソッド:POST

パス
```
/api/v1.0/users
```

リクエスト
```json
{
  "username": "testuser",
  "password": "password123",
  "email": "test@example.com"
}
```

レスポンス
```json
{
  "status": 201,
  "message": "User created successfully",
  "data": {
    "uuid": "019770ab-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "username": "testuser",
    "email": "test@example.com"
  }
}
```

### ログイン
メソッド:POST

パス
```
/api/v1.0/auth/login
```

リクエスト
```json
{
  "identifier": "test@example.com",
  "password": "password123"
}
```

レスポンス
```json
{
  "status": 200,
  "message": "ログインしました",
  "data": {
    "accessToken": "eyJ...",
    "refreshToken": "eyJ..."
  }
}
```
※レスポンスボディに加えて、`Set-Cookie` で `access_token` と `refresh_token` が付与されます。以降のクライアントAPIではこのCookie（または `Authorization: Bearer <accessToken>`）が必要です。
### デバイス登録 (OwnerToken発行申請)
メソッド:POST

パス
```
/api/v1.0/device/issue-token
```

リクエスト (要ログイン)
```json
{
  "deviceUuid": "デバイスが自動生成したUUID",
  "name": "センサー1号"
}
```

レスポンス
```json
{
  "status": 201,
  "message": "OwnerToken を発行しました。",
  "data": {
    "ownerToken": "eyJ...",
    "deviceUuid": "xxxxx",
    "name": "センサー1号",
    "expiresAt": "2026-07-23 12:00:00"
  }
}
```
※ここで発行された `ownerToken` をBLE経由でマイコンに渡し、マイコンはそれを使って自己登録を行います。
